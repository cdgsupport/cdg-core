CDG Core — Component Style Guide

Live reference for every UI component in the Shadcn-inspired admin design system. This page links directly to css/admin-style.css — edit that file and reload to see changes here and in wp-admin at the same time. All classes are prefixed cdg- and scoped under .cdg-v2; markup mirrors the PHP helpers in class-admin.php (card(), row(), sw(), radio_group(), check_item()).
